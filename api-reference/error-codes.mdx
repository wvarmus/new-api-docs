# 错误码说明

| 错误码 | 说明 |
| --- | --- |
| 400 | 请求参数错误 |
| 401 | 未授权 / API Key 无效 |
| 403 | 权限不足 |
| 404 | 资源不存在 |
| 429 | 请求过于频繁（速率限制） |
| 500 | 服务器内部错误 |
| 501 | 接口未实现 |

## 错误响应格式

```json
{
  "error": {
    "message": "错误信息",
    "type": "invalid_request_error",
    "code": "invalid_api_key"
  }
}
```

## 速率限制

不同账户、线路和上游服务状态下，默认限制可能有所不同。具体限制可在个人中心查看。
