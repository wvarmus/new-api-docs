# 音频转录与翻译接口 (ASR)

将您上传的音频录音文件，通过 AI 的语音识别能力转化为纯文本，或者直接翻译为英文。

## 1. 音频转录 (Transcriptions)

识别录音中的原语种并转换为对应的文本文字。常用于会议纪要、语音助手输入。

> **接口端点：** `POST /v1/audio/transcriptions`
> **请求格式：** `multipart/form-data`
> **身份认证：** `Authorization: Bearer 您的API_KEY`

### 核心参数说明表

| 字段名称 | 字段类型 | 是否必填 | 说明 |
| :--- | :--- | :--- | :--- |
| **file** | file | **必填** | 音频文件（支持 mp3, mp4, mpeg, mpga, m4a, wav, webm）。 |
| **model** | string | **必填** | 识别模型，例如 `whisper-1`。 |
| **language** | string | 选填 | 预设音频的语言 ISO-639-1 代码（如 `zh` 代表中文），提供此项可显著提升识别精准度。 |
| **response_format**| string | 选填 | 返回格式。默认为 `json`，若需要生成带时间轴的字幕，可设置为 `srt` 或 `vtt`。 |
| **temperature** | number | 选填 | 采样温度（0-1），控制生成的随机性。 |

## 2. 音频翻译 (Translations)

自动识别上传的非英文音频，并**直接将其翻译成英文文本**返回。

> **接口端点：** `POST /v1/audio/translations`
> **请求格式：** `multipart/form-data`
> **身份认证：** `Authorization: Bearer 您的API_KEY`

*注：核心参数结构与转录接口一致，通过表单传入 `file` 和 `model` 即可获取直接翻译后的英文结果。*
