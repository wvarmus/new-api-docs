LobeChat 是一款开源的现代化大模型交互框架。它以其极具设计感的 UI 界面、强大的插件生态（如联网搜索、生成图片、获取网页摘要）以及优秀的语音识别（TTS/STT）能力而广受进阶用户喜爱。

通过接入无限星河AI，您可以低成本激活 LobeChat 的全部潜能。

---

## 一、 软件获取与部署

您可以根据自己的技术背景选择合适的使用方式：

* **官方在线体验**：[https://chat-preview.lobehub.com](https://chat-preview.lobehub.com) （可以直接在网页端使用）
* **GitHub 下载桌面端**：[https://github.com/lobehub/lobe-chat/releases](https://github.com/lobehub/lobe-chat/releases) （支持 Windows, macOS, Linux）
* **私有化部署**：支持一键部署到 Vercel, Zeabur 或通过 Docker 运行在您自己的服务器上。

---

## 二、 接入无限星河AI 配置步骤

1.  **打开设置**：进入 LobeChat 界面后，点击左下角的 **[设置]** 图标（或者使用快捷键 `Cmd/Ctrl + ,`）。
2.  **进入模型面板**：在左侧菜单栏中找到 **[语言模型]**，然后点击 **[OpenAI]** 标签页。
3.  **填写 API 密钥**：在 **API Key** 输入框中，填入您在无限星河后台生成的 `sk-` 密钥。
4.  **修改接口代理地址**：在 **接口代理地址** 输入框中，填入完整的中转网关地址：
    `https://infistar.ai/v1`
5.  **检查连通性**：点击下方的 **[检查]** 按钮。如果提示“检查通过”，则说明配置成功。

## 三、 LobeChat 核心功能推荐

### 1. 助手市场 (Agents)
LobeChat 内置了极为丰富的角色市场。您可以直接下载并应用各种专家预设（如“小红书爆款文案生成器”、“Python 代码审计专家”），配合无限星河提供的高级模型，产出质量极高。

### 2. 插件生态 (Plugins)
在对话框输入区域点击“插件”图标，您可以启用：
* **搜索引擎**：让模型具备实时联网能力。
* **网页读取**：扔给它一个 URL，自动总结文章内容。
* *注意：使用插件会增加 Token 的消耗，建议配合性价比极高的 `gpt-4o-mini` 模型使用。*

### 3. 多模态视觉能力
如果您的模型选择了支持视觉的型号（如 `gpt-4o` 或 `claude-3-7-sonnet`），您可以直接将图片拖拽进聊天框，让 AI 进行分析或翻译。

## 四、 常见问题排查 (FAQ)

### Q1：连通性检查失败或一直转圈？
* 请检查“接口代理地址”是否漏掉了结尾的 `/v1`。
* 确保您的网络环境没有被本地防火墙拦截。

### Q2：如何获取最新的模型列表？
* 在刚才的 **[OpenAI]** 设置页面底部，点击 **[获取模型列表]** 按钮。LobeChat 会自动从无限星河网关拉取您当前账户可用的所有模型（包括 Claude 和 Gemini 等非 OpenAI 原厂模型）。
* 您也可以在“自定义模型名称”栏中手动添加，多个模型用逗号隔开，例如：`gpt-4o,claude-3-7-sonnet,o1-preview`

### Q3：为什么对话时提示 402 或余额不足？
* 请登录无限星河后台，检查您的账号余额是否 > 0。
* 插件调用和多模态识图都会额外消耗 Token，请确保余额充足。

## 五、 推荐模型搭配方案

* **日常助理/极速联网**：`gpt-4o-mini` (响应极快，消耗低)
* **复杂长文/多模态处理**：`claude-3-7-sonnet` (排版美观，逻辑清晰)
* **深度代码与数学推理**：`o1-preview` 或 `o3-mini`
