SillyTavern（简称酒馆）是一款专为角色扮演、互动小说及创意写作设计的本地前端界面。配合无限星河AI 的高性能模型，您可以获得极具沉浸感的对话体验。

---

## 一、 软件获取

SillyTavern 是一个开源项目，通常有以下几种运行方式：
* **本地安装**：通过 [GitHub 官网](https://github.com/SillyTavern/SillyTavern) 下载并根据说明使用 Node.js 运行。
* **移动端**：通过 Termux (安卓) 或相关第三方封装版本运行。
* **一键包**：国内社区（如 API 社区、酒馆论坛）常有打包好的扩展版，内置了中文补丁和常用插件。

---

## 二、 基础配置步骤

要在酒馆中使用无限星河AI 的接口，请按照以下参数进行设置：

### 1. 进入连接设置
在酒馆界面顶部点击 **[插头图标] (API Connections)**。

### 2. 选择 API 类型
* **API 项**：选择 **OpenAI**。
* **API 风格**：保持默认的 **OpenAI** 即可。

### 3. 填写关键参数
请严格按照以下标准填写，以确保连接成功：

* **API 地址 (API URL)**：填入 `https://api.wxxingheai.com/v1`
* **API 密钥 (API Key)**：填入您在无限星河AI 后台生成的 `sk-` 密钥。
* **点击连接 (Connect)**：设置完成后点击“连接”按钮。若圆点变绿，说明连接成功。

## 三、 进阶配置：模型与提示词

### 1. 模型选择 (Model)
连接成功后，在下方的模型下拉菜单中选择您想使用的模型。
* **推荐方案**：
    * **沉浸文采**：强烈推荐 `claude-3-7-sonnet` 或 `claude-3-5-sonnet`。Claude 系列在角色扮演逻辑和词汇丰富度上公认最强。
    * **严谨剧情**：推荐 `gpt-4o`。

### 2. 角色预设 (Chat Completion Settings)
在设置中，您可以调整 **Temperature (温度)**。
* **建议值**：`0.8 - 1.2` 之间。数值越高，AI 的回答越具有创造力和随机性；数值越低，回答越严谨。

### 3. 上下文长度 (Context Size)
无限星河AI 支持超长上下文。
* 建议将酒馆内的上下文限制设置为 **8192** 或以上（根据您的模型选择，Claude 支持极长文本，但请注意高上下文会消耗更多 Token）。

## 四、 常见问题排查 (FAQ)

### Q1：提示 "Invalid API Key" 或连接失败？
* 检查地址是否包含 `https://` 且结尾带有 `/v1`。
* 确保您的无限星河账户余额充足。

### Q2：AI 回复内容被截断？
* 请在酒馆设置中调大 **Response Length (回复长度)**，建议设为 `0` (不限制) 或 `1000` 以上。

### Q3：为什么 Claude 模型有时候不说话？
* 这通常是因为请求内容触发了原厂模型的安全审查或策略限制。建议您先检查输入内容是否包含敏感、违规或高风险表达，并尽量使用更明确、合规的提示词重新描述需求。若持续出现问题，可切换到其他更适合当前任务的模型，或联系平台支持进一步排查。
