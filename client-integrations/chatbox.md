## 二、 接入无限星河AI 配置步骤

1.  **启动 Chatbox**：打开软件后，点击左下角的 **[设置]**（齿轮图标）。
2.  **模型提供方**：在下拉菜单中选择 **OpenAI API**。
3.  **API 密钥 (API Key)**：填入您在无限星河后台生成的 `sk-` 密钥。
4.  **API 域名 (Proxy)**：填入 `https://infistar.ai`
    > *注：Chatbox 通常会自动补全后缀。如果连接测试失败，请尝试填写完整地址：`https://infistar.ai/v1`*
5.  **模型 (Model)**：点击“刷新模型列表”或手动输入模型 ID。
    * **模型选择**：可在模型广场选择适合日常对话、长文本或创作任务的模型。

## 三、 进阶功能推荐

### 1. 消息引用与上下文控制
在对话框中，您可以点击历史消息进行引用。此外，在设置中可以调整“携带历史消息数量”，建议设置为 **5-10 条**，以平衡对话连贯性与 Token 消耗。

### 2. 角色预设 (Prompts)
Chatbox 内置了丰富的角色库。您可以导入“翻译官”、“代码专家”或“周报助手”预设，配合无限星河AI 的高阶模型，处理特定任务效果更佳。

### 3. 数据本地存储
所有的聊天记录均存储在您的本地设备上。如果您需要更换设备，可以使用“导出数据”功能，确保隐私安全且不丢失重要对话。

## 四、 常见问题排查 (FAQ)

### Q1：点击“检查连接”提示失败？
* **网络检查**：确保您的网络可以正常连接到无限星河服务。
* **地址校验**：请检查 API 域名是否多填了空格，或者尝试在末尾加上 `/v1`。
* **余额核对**：登录无限星河后台，确认您的账户余额是否大于 0。

### Q2：模型下拉菜单是空的？
* Chatbox 有时无法实时拉取所有中转模型。您可以点击“自定义模型”，手动输入类似 `gpt-4o` 或 `claude-3-7-sonnet` 的 ID 即可使用。

### Q3：回复速度慢或经常中断？
* 请在设置中开启 **“流式输出 (Stream)”**。
* 检查您的网络环境，或尝试更换无限星河提供的备用接入节点。
