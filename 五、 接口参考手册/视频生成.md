# 视频生成与管理接口 (Videos)

无限星河AI 聚合了目前最领先的 AI 视频创作模型（兼容 Sora 格式、快手可灵 Kling、字节即梦 Jimeng）。由于视频生成通常耗时较长，平台主要采用“异步任务提交 + 轮询查询状态”的机制。

## 1. 提交视频生成任务

> **标准端点：** `POST /v1/videos` 
> **可灵 (Kling) 专属端点：** `POST /kling/v1/videos/text2video` 或 `/kling/v1/videos/image2video`
> **身份认证：** `Authorization: Bearer 您的API_KEY`

提交任务后，接口不会立刻返回视频，而是会返回一个 **任务 ID (task_id)**。

### 核心参数说明表

| 参数名称 | 是否必填 | 参数说明 |
| :--- | :--- | :--- |
| **model** | **必填** | 视频模型标识，如 `sora-turbo`、`kling-v1` 等。 |
| **prompt** | **必填** | 文字描述提示词，越详细生成的画面越贴合想象。 |
| **image** / **image_urls**| 选填 | 参考图链接（在图生视频模式下必须提供）。 |
| **duration** | 选填 | 指定期望生成的视频时长（秒），具体支持的时长受限于底层模型。 |
| **width** / **height** | 选填 | 视频的宽度和高度（分辨率）。 |

## 2. 视频任务状态轮询

获取到任务 ID (task_id) 后，您需要在业务系统中定期（例如每隔 5-10 秒）通过 GET 请求查询该任务的处理状态。

> **查询端点示例：** `GET /v1/video/generations/{task_id}`
> **身份认证：** `Authorization: Bearer 您的API_KEY`

### 状态流转说明：

1. **queued**：任务已受理，正在排队等待集群算力分配。
2. **in_progress**：AI 正在渲染生成视频。
3. **completed**：生成完成！此时接口的返回数据中会包含一个有效期内的 `url` 字段，客户端可直接使用该链接播放或下载 MP4 文件。
4. **failed**：生成失败。接口会一并返回失败原因（常见原因为提示词触发了内容风控审查）。
