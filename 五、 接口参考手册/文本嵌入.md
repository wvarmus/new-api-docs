# 文本嵌入接口 (Embeddings)

用于将文本段落转化为多维数值向量。常用于企业私有知识库构建、语义相似度搜索以及 RAG（检索增强生成）场景。

> **通用端点：** `POST /v1/embeddings`
> **Gemini 专用端点：** `POST /v1/engines/{model}/embeddings`
> **身份认证：** `Authorization: Bearer 您的API_KEY`

## 核心参数说明表

| 参数名称 | 是否必填 | 参数说明 |
| :--- | :--- | :--- |
| **model** | **必填** | 嵌入模型名称，例如 `text-embedding-3-small` 或 `text-embedding-ada-002`。 |
| **input** | **必填** | 要转换的文本内容。支持传入单个字符串，或包含多段文本的数组以进行批量高效转换（单次最多 2048 条）。 |
| **encoding_format** | 选填 | 返回向量数据的格式，默认为 `float`（浮点数数组），也可选择 `base64`。 |
| **dimensions** | 选填 | 指定输出向量的维度（仅限支持调整维度的模型生效）。 |
