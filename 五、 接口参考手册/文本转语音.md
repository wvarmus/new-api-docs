# 文本转语音接口 (TTS)

将输入的文字合成为高度拟真、带有情感色彩的自然人声录音文件。

> **接口端点：** `POST /v1/audio/speech`
> **身份认证：** `Authorization: Bearer 您的API_KEY`

## 核心参数说明表

在发送请求时，请提供以下参数：

| 参数名称 | 是否必填 | 参数说明 |
| :--- | :--- | :--- |
| **model** | **必填** | 语音合成模型，例如 `tts-1`（常规速度）或 `tts-1-hd`（高保真音质）。 |
| **input** | **必填** | 要转换的文本内容（最多支持 4096 个字符）。 |
| **voice** | **必填** | 声音类型选择。可用官方音色包括：`alloy` (合金), `echo` (回声), `fable` (寓言), `onyx` (缟玛瑙), `nova` (新星), `shimmer` (微光)。 |
| **response_format**| 选填 | 希望输出的音频文件格式。默认为 `mp3`，同时也支持 `opus`, `aac`, `flac`, `wav` 格式。 |
| **speed** | 选填 | 语速控制参数，范围从 0.25 到 4.0，默认正常语速为 1.0。 |

## 返回值说明

*注：请求成功后，接口不会返回常见的 JSON 文本，而是**直接返回二进制的音频文件流数据**。您可以将其直接保存为 `.mp3` 文件，或者在前端网页中将其作为 `<audio>` 标签的播放源进行直接播放。*
