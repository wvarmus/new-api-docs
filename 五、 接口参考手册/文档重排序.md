# 文档重排序接口 (Rerank)

在 RAG（检索增强生成）业务场景中，该接口根据用户的自然语言查询词，对向量数据库粗筛出来的一系列候选文档进行深度的二次智能打分和重排序，提取出相关性最高的结果。

> **接口端点：** `POST /v1/rerank`
> **身份认证：** `Authorization: Bearer 您的API_KEY`

## 核心参数说明表

在发送请求时，请在请求体中提供以下参数：

| 参数名称 | 是否必填 | 参数说明 |
| :--- | :--- | :--- |
| **model** | **必填** | 使用的重排序模型名称。 |
| **query** | **必填** | 用户的实际搜索文本或提问。 |
| **documents** | **必填** | 需要进行相关性重排序的文本片段（候选文档）数组列表。 |
| **top_n** | 选填 | 指定最终只返回排名前 N 个最相关的结果。 |
| **return_documents**| 选填 | 布尔值，设为 true 时，返回的结果中会一并携带原文档的文本内容，默认为 false。 |
