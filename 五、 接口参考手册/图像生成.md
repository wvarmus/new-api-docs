# 图像生成与编辑接口 (Images)

支持将用户的创意文本一键转化为高质量画作，或对现有图片进行智能编辑。

## 1. 图像生成 (Generations)

支持 OpenAI 的 DALL-E 系列以及阿里通义万象等多种绘图模型。

> **接口端点：** `POST /v1/images/generations`
> **身份认证：** `Authorization: Bearer 您的API_KEY`

### 核心参数说明表

| 参数名称 | 是否必填 | 参数说明 |
| :--- | :--- | :--- |
| **model** | 选填 | 图像生成模型名称，如 `dall-e-3`、`wanx-v1` 等。 |
| **prompt** | **必填** | 对您想要生成的画面的详细英文或中文描述（提示词）。 |
| **size** | 选填 | 图片的分辨率尺寸，如 `1024x1024`，`1792x1024` 等。 |
| **quality** | 选填 | 图片质量等级，可选 `standard` (标准) 或 `hd` (高清)。 |
| **style** | 选填 | 画风选择，如 `vivid` (生动) 或 `natural` (自然)。 |
| **n** | 选填 | 需要生成的图片张数（默认 1 张）。 |

> **\[图片备注：一张包含用户提示词“一只可爱的猫咪在草地上玩耍”和接口实际返回的生成美图的对比界面截图。\]**

## 2. 图像编辑 (Edits)

在给定原始图像和提示词的情况下，对图像的指定区域进行编辑或扩展。

> **接口端点：** `POST /v1/images/edits`
> **请求格式：** 必须使用 `multipart/form-data` 格式上传文件。
> **身份认证：** `Authorization: Bearer 您的API_KEY`

### 核心参数说明表

| 字段名称 | 字段类型 | 是否必填 | 说明 |
| :--- | :--- | :--- | :--- |
| **image** | file | **必填** | 需要编辑的原始正方形图像文件（支持 PNG）。 |
| **mask** | file | 选填 | 附加的透明遮罩文件，标识出允许 AI 修改的区域。 |
| **prompt** | string | **必填** | 修改指令描述。 |
