## 一、 什么是 Token？

**Token** 是人工智能模型处理文本的最小单位。您可以将其理解为文字的“碎片”或“零件”。

* **汉字**：1 个汉字通常占用 1.5 到 2 个 Token。
* **英文**：1 个单词通常占用 1 到 1.3 个 Token。
* **标点与空格**：同样会占用少量的 Token。

## 二、 计费组成部分

每一次 API 请求产生的费用由以下三部分组成：

### 1. 输入 Token (Input)
即您发送给 AI 的指令、问题以及上传的上下文素材（如文档内容）。

### 2. 上下文记忆 (Context)
在连续对话中，为了让 AI 记得之前的聊天内容，客户端软件通常会将之前的对话记录连同新问题一起发送。这部分历史记录也会计入“输入 Token”中。
* **省钱小贴士**：如果您开启了“长记忆”模式，随着对话轮数增加，单次请求的 Token 消耗会逐渐增大。建议定期清理不必要的历史记录。

### 3. 输出 Token (Output)
即 AI 为您生成的回答内容。由于生成过程需要消耗更高的算力，通常输出 Token 的单价会略高于输入 Token。

## 三、 充值比例与结算单位

为了让计费更加直观，我们简化了复杂的汇率结算：

* **结算货币**：平台统一使用“美元 ($)”作为结算单位，直接对应各大模型原厂的计费标准。
* **充值比例**：**1 元人民币 (RMB) = 1 美元 ($)**。
* **透明体验**：这意味着您充值 10 元人民币，账户中将直接显示 10 美元。您可以直接参照 OpenAI 或 Anthropic 的官方原价进行消费对比，没有任何隐性加价。

## 四、 实时倍率查询

不同的模型因其思考深度和资源占用不同，其 Token 单价差异极大（例如 GPT-4o 的单价通常是 GPT-3.5 的数十倍）。

* **费率透明**：我们实时同步全球供应商的费率波动。
* **查询路径**：您可以登录控制台，进入 **[费率查询]** 页面，实时查看每一个模型的：
    * 每百万 Token 的输入单价。
    * 每百万 Token 的输出单价。
    * 当前模型的可用状态。

## 五、 计费常见问题

* **问：请求失败会扣费吗？**
    * 答：不会。只有当服务器成功返回内容时，系统才会实时扣除对应的费用。
* **问：图片和文件怎么计费？**
    * 答：对于多模态模型（如 GPT-4o），图片会根据分辨率大小折算为固定数量的 Token 进行计费，具体标准可在费率表查看。
