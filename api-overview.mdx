# API 总览

无限星河 AI 提供完整的 AI 模型接口，兼容 OpenAI API 格式，并支持多种主流 AI 服务提供商。

## 基础地址

```bash
https://infistar.ai
```

OpenAI 兼容客户端通常填写以下地址：

```bash
https://infistar.ai/v1
```

## 认证方式

```bash
Authorization: Bearer {api_key}
```

> 调用所需令牌（即 API Key）可在控制台的“令牌管理”中创建和获取。

## 当前覆盖能力

- 模型列表
- 文本与对话
- 嵌入与检索
- 内容安全
- 图像
- 音频
- 视频
- 实时语音

## 说明

- `API 文档` Tab 以 OpenAPI 描述驱动，适合查看请求体、响应体与调用示例。
- 实时语音、错误码说明、常见 HTTP 状态码与速率限制等内容作为 API 文档的补充说明页保留在同一 Tab 中。
- 网关配置、身份认证与高级功能等接入说明仍保留在“技术对接规范”分组中，不与接口定义混排。
