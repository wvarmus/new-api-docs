---
title: 常见 HTTP 状态码与故障排查
---

在调用 API 的过程中，您可能会遇到系统返回的各种状态码。了解这些代码的含义，能帮助您快速定位并解决 90% 的问题。

---

## 1. 成功响应 (2xx)

* **200 OK**：请求成功。AI 已开始生成内容或已完整返回结果。

## 2. 客户端错误 (4xx) —— 需检查您的配置

此类错误通常由本地设置或账户状态引起。

| 状态码 | 错误名称 | 核心原因 | 解决建议 |
| :--- | :--- | :--- | :--- |
| **401** | Unauthorized | 密钥 (API Key) 无效 | 1. 检查 Key 是否复制完整（带 `sk-`）；<br />2. 确保 Header 中包含 `Bearer ` 且有一个空格；<br />3. 检查 Key 是否在后台已被手动删除。 |
| **402** | Payment Required | 账户余额不足 | 1. 登录后台检查余额是否已耗尽；<br />2. 请前往“财务中心”充值或通过“卡密兑换”补充额度。 |
| **404** | Not Found | 接口地址或模型错误 | 1. 检查 Base URL 是否漏掉 `/v1`；<br />2. 检查 `model` 参数拼写是否正确（如 `gpt-4o` 误写为 `gpt4o`）。 |
| **429** | Too Many Requests | 触发频率限制 | 1. 您的调用速度超过了当前账号等级的限制（RPM/TPM）；<br />2. 请降低并发数，或联系客服申请提升账号等级。 |
| **400** | Bad Request | 请求参数格式错误 | 1. 检查 JSON 语法是否正确（如逗号缺失）；<br />2. 检查是否上传了模型不支持的参数（如非视觉模型上传图片）。 |

---

## 3. 服务端错误 (5xx) —— 网关或原厂故障

此类错误通常与您的配置无关，多为网络或上游模型供应商波动。

* **500 Internal Server Error**：
    * **原因**：网关内部错误或下游供应商瞬间崩溃。
    * **解决**：无限星河AI 具备自动灾备切换功能，通常**刷新或等待 10 秒重试**即可恢复。
* **502 / 504 Gateway Timeout**：
    * **原因**：上游模型生成速度过慢或网络连接中断。
    * **解决**：检查您的 `timeout` 设置是否太短（建议设为 60s 以上）；若大面积出现，请查看官网公告。

---

## 4. 故障排查“三板斧”

如果您遇到无法解决的问题，请按以下顺序操作：

1.  **核对 Base URL**：确保填写的是 `https://infistar.ai/v1`。
2.  **检查余额**：确认后台显示的美元余额 > 0。
3.  **渠道测试**：在后台 **[渠道管理]** 页面找到对应渠道并点击“测试”。
    * 若渠道测试正常，说明大概率是您的软件设置问题；
    * 若渠道测试也异常，请联系平台技术支持。

---

## 5. 技术支持渠道

若通过上述步骤仍未解决，请准备好以下信息联系客服：
* 您的无限星河账号。
* 报错信息的完整截图。
* 您正在调用的模型名称（如 `claude-3-7-sonnet`）。
